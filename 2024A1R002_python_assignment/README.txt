MIET Campus Canteen Ordering and Billing System  (COM-501 Python Assignment)

How to run (Python 3 required, no extra libraries):
    python main.py

Files
    main.py               - final console application (menu-driven)       [Milestone 5]
    canteen_utils.py      - user-defined module: subtotal, discount, bill [Milestone 4]
    canteen_order.py      - CanteenOrder class                            [Milestone 3]
    canteen_storage.py    - file handling: save and read order records    [Milestone 5]
    canteen_orders.txt    - sample order records created by the program
    main_milestone4.py    - Milestone 4 main program (module import + time demo)
    milestones/           - earlier versions: m1_basic_bill.py, m2_menu_loop.py, m3_oop.py
